## How to Update Metadata

### For Static Pages
Edit the `metadata` export in each `page.tsx` file:

```typescript
import type { Metadata } from "next"

export const metadata: Metadata = {
  title: "Your Unique Title Here",
  description: "Your unique description 120-160 characters.",
  alternates: {
    canonical: "https://prioritydispatchllc.com/your-page",
  },
  openGraph: {
    title: "Your Unique Title Here",
    description: "Your unique description.",
    url: "https://prioritydispatchllc.com/your-page",
    siteName: "Priority Dispatch LLC",
    type: "website",
  },
}
```

### For Blog Posts
Each blog post should dynamically generate metadata:

```typescript
import type { Metadata } from "next"

export async function generateMetadata(): Promise<Metadata> {
  return {
    title: "Blog Post Title | Priority Dispatch Blog",
    description: "Engaging description 120-160 characters about this post.",
    alternates: {
      canonical: "https://prioritydispatchllc.com/blog/post-slug",
    },
    openGraph: {
      title: "Blog Post Title | Priority Dispatch Blog",
      description: "Engaging description about this post.",
      url: "https://prioritydispatchllc.com/blog/post-slug",
      type: "article",
      publishedTime: "2026-10-09T00:00:00.000Z",
      authors: ["Muhammad Faisal Bilal"],
    },
  }
}
```
