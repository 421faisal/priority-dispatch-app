## 🔍 Google Search Console Setup

### Step 1: Add Property
1. Go to [Google Search Console](https://search.google.com/search-console)
2. Click "Add Property"
3. Choose "URL prefix" method
4. Enter: `https://prioritydispatchllc.com`

### Step 2: Verify Ownership
Choose one of these verification methods:

**Option A: HTML File Upload**
1. Download the verification file from Google
2. Upload to `/public/` directory
3. Verify it's accessible at: `https://prioritydispatchllc.com/google[code].html`
4. Click "Verify" in Search Console

**Option B: DNS Verification**
1. Get TXT record from Google
2. Add to your domain's DNS settings
3. Wait for DNS propagation (can take up to 48 hours)
4. Click "Verify" in Search Console

**Option C: Google Analytics**
1. If Google Analytics is already installed (it is: G-LP1X3P58HM)
2. Use the same Google account
3. Select "Google Analytics" verification method

### Step 3: Submit Sitemap
1. In Search Console, go to "Sitemaps" in left menu
2. Enter: `sitemap.xml`
3. Click "Submit"
4. Wait 24-48 hours for Google to crawl

### Step 4: Request Indexing for Key Pages
Manually request indexing for important pages:
1. Go to "URL Inspection" tool
2. Enter each URL below
3. Click "Request Indexing"

**Priority Pages to Index:**
- https://prioritydispatchllc.com/
- https://prioritydispatchllc.com/services
- https://prioritydispatchllc.com/carrier-setup
- https://prioritydispatchllc.com/blog
- https://prioritydispatchllc.com/blog/what-is-bonded-carrier-trucking
- https://prioritydispatchllc.com/blog/what-is-twic-card-trucking
- https://prioritydispatchllc.com/blog/what-is-tsa-certified-trucking

### Step 5: Monitor Performance
- Check "Performance" report weekly
- Monitor "Coverage" for indexing issues
- Review "Enhancements" for mobile usability
- Check "Core Web Vitals" for performance metrics

## 🔵 Bing Webmaster Tools Setup

### Step 1: Add Site
1. Go to [Bing Webmaster Tools](https://www.bing.com/webmasters)
2. Click "Add a site"
3. Enter: `https://prioritydispatchllc.com`

### Step 2: Verify Ownership
Choose verification method:

**Option A: XML File**
1. Download BingSiteAuth.xml file
2. Upload to `/public/` directory
3. Verify accessible at: `https://prioritydispatchllc.com/BingSiteAuth.xml`
4. Click "Verify"

**Option B: Import from Google Search Console**
1. If already verified in Google Search Console
2. Click "Import from Google Search Console"
3. Authorize with same Google account

### Step 3: Submit Sitemap
1. Go to "Sitemaps" section
2. Enter: `https://prioritydispatchllc.com/sitemap.xml`
3. Click "Submit"

### Step 4: Configure Settings
1. Set crawl rate (recommended: Normal)
2. Enable email notifications for issues
3. Review URL inspection tool
